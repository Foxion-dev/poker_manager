## Приоритеты реализации

### MVP (Минимально жизнеспособный продукт)
1. Аутентификация
2. CRUD для турниров
3. Базовый список румов
4. Простая статистика (общий баланс, количество турниров)
5. Базовая таблица турниров

### Вторая итерация
1. График динамики банкролла
2. Расширенная статистика (ABI, ROI, ITM)
3. Фильтры и поиск
4. Управление балансами в румах

### Третья итерация
1. Экспорт данных
2. Темная тема
3. Оптимизация производительности
4. Дополнительные метрики
