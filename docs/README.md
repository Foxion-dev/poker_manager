# Документация Poker Manager

Poker Manager — веб-приложение для учёта турниров, паков и балансов по покерным румам с интеграцией Telegram-бота.

## Разделы

- **[Для пользователей](users/README.md)** — как пользоваться приложением и ботом в Telegram.
- **[Для администратора и разработчика](admin/README.md)** — установка, деплой, настройка бота, разработка.
