# Настройка Telegram-бота на сервере

Пошаговая инструкция по подключению бота к приложению Poker Manager.

---

## 1. Создание бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду `/newbot`.
3. Введите имя бота (например, «Poker Manager»).
4. Введите username бота (должен заканчиваться на `bot`, например `poker_manager_bot`).
5. BotFather пришлёт **токен** вида `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`.
6. Сохраните токен — он понадобится в админке.

**Важно:** BotFather только создаёт бота и выдаёт токен. Он **не знает** и **не настраивает** адрес вашего сервера. Откуда принимать запросы, Telegram узнаёт позже — когда **ваше приложение** само сообщит ему URL (шаг 4).

---

## 2. Как Telegram узнаёт адрес вашего сервера

Telegram не получает адрес от BotFather. Адрес вебхука регистрирует **ваше приложение**:

1. Вы вставляете токен в админку и нажимаете **«Сохранить»** (раздел 4).
2. Наш сервер в этот момент вызывает Telegram API:  
   `POST https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook`  
   с параметром `url=https://ваш-домен.com/api/telegram/webhook`.
3. Telegram запоминает: «все обновления (сообщения, команды) для этого бота слать на этот URL».
4. С этого момента при каждом сообщении боту Telegram отправляет POST-запрос на ваш сервер, и бот «оживает».

То есть **сообщение Telegram о нашем сервисе происходит при сохранении настроек в админке** — дополнительно ничего вручную в BotFather указывать не нужно.

---

## 3. Требования к серверу

- Сайт должен быть доступен по **HTTPS** (Telegram принимает вебхуки только по HTTPS, кроме `127.0.0.1`).
- В `.env` должен быть задан **APP_URL** — полный адрес сайта без слэша в конце, например:
  - `https://yourdomain.com`
  - `https://poker.example.com`

---

## 4. Настройка приложения

1. Убедитесь, что выполнены миграции (таблицы `telegram_bot_settings`, `telegram_link_codes`, `user_settings` и т.д.):
   ```bash
   php artisan migrate
   ```

2. В `.env` на сервере задайте корректный **APP_URL**:
   ```env
   APP_URL=https://yourdomain.com
   ```

3. После изменения `.env` при необходимости сбросьте кэш конфигурации:
   ```bash
   php artisan config:clear
   ```

---

## 5. Подключение бота в админке

1. Войдите в приложение под учётной записью **администратора**.
2. Откройте раздел **Админка** → **Настройки** → вкладка **Telegram**.
3. Вставьте **токен бота** из BotFather в поле «Токен бота».
4. Включите опцию **«Бот включён»**.
5. Нажмите **Сохранить**.

После сохранения приложение само вызовет Telegram API и зарегистрирует вебхук по адресу:

`https://yourdomain.com/api/telegram/webhook`

Дополнительно ничего настраивать не нужно. Именно в этот момент Telegram и узнаёт адрес вашего сервера (см. раздел 2).

---

## 6. Проверка работы вебхука

1. Найдите бота в Telegram по username (например, `@poker_manager_bot`).
2. Нажмите **Start** или отправьте `/start`.
3. Должно прийти сообщение с просьбой получить код в настройках приложения и отправить `/start КОД`.
4. Привяжите аккаунт (шаг 6) и отправьте `/balance` — должен прийти список балансов по румам.

Если сообщения не приходят — см. раздел **«Почему бот не реагирует»** ниже.

---

## 6.1. Почему бот не реагирует на /start

В **самом боте в BotFather** ничего дополнительно включать не нужно: бот по умолчанию может получать сообщения. Реакция на команды зависит только от того, что Telegram вызывает ваш сервер по вебхуку.

Проверьте по шагам:

**1. Вебхук установлен и совпадает с вашим доменом**

На сервере выполните:

```bash
php artisan telegram:webhook-info
```

- Если выведено «Вебхук не установлен» — зайдите в админку → Настройки → Telegram, убедитесь, что токен вставлен и включён «Бот включён», нажмите **Сохранить**. После этого снова выполните `php artisan telegram:webhook-info` и проверьте, что появился URL.
- Если вебхук указан — URL должен быть вида `https://ваш-домен.com/api/telegram/webhook`. Если там другой домен или `http://` — в `.env` исправьте **APP_URL** на правильный HTTPS-адрес, затем в админке снова сохраните настройки Telegram.

**2. APP_URL — обязательно HTTPS**

В `.env` должно быть:

```env
APP_URL=https://ваш-домен.com
```

Без `https://` Telegram вебхуки не примет (кроме localhost). После смены APP_URL выполните `php artisan config:clear` и заново сохраните настройки бота в админке.

**3. Ошибки при обработке запроса**

Если вебхук в Telegram указан верно, но бот всё равно молчит — возможно, на сервере падает код при обработке. Откройте лог:

```bash
tail -f storage/logs/laravel.log
```

Отправьте боту `/start`. В логе не должно появляться записей с текстом `Telegram webhook error`. Если такие есть — по стеку ошибки можно понять, что исправить (БД, права, неверный формат данных и т.д.).

**4. (Необязательно) Меню команд в BotFather**

В BotFather можно задать список команд, чтобы у бота отображалось меню с `/start` и `/balance`:

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/mybots` → выберите вашего бота.
3. **Bot Settings** → **Menu Button** или **Commands**.
4. Задайте команды, например:
   - `start` — Привязать аккаунт или начать
   - `balance` — Баланс по румам

Это только подсказка для пользователей; на то, что бот **реагирует** на `/start`, это не влияет.

---

## 7. Настройка пользователей (привязка к боту)

1. Пользователь входит в приложение и переходит в **Настройки** → вкладка **Telegram**.
2. Нажимает **«Получить код»** — отображается код (например, `ABC123`) и время действия (обычно 10 минут).
3. В Telegram открывает вашего бота и отправляет: `/start ABC123` (подставив свой код).
4. Бот отвечает, что аккаунт привязан.
5. Команда **/balance** выводит балансы по всем подключённым румам, кроме тех, что пользователь скрыл в настройках («отключённые» румы).

## 8. Nginx (если используется)

Убедитесь, что запросы к API не обрезаются и проксируются в приложение. Пример для Laravel:

```nginx
location /api/ {
    try_files $uri $uri/ /index.php?$query_string;
}
```

И что PHP получает тело запроса (для POST от Telegram):

```nginx
location ~ \.php$ {
    fastcgi_param REQUEST_METHOD $request_method;
    fastcgi_param CONTENT_TYPE $content_type;
    fastcgi_param CONTENT_LENGTH $content_length;
    fastcgi_pass unix:/var/run/php/php-fpm.sock;
    # ... остальные параметры
}
```

В типовой конфигурации Laravel это уже учтено.

## 9. Локальная разработка

Telegram не отправляет вебхуки на `http://` (кроме localhost). Для проверки бота локально:

1. Поднять туннель с HTTPS (например, [ngrok](https://ngrok.com)) на порт вашего приложения.
2. В `.env` указать `APP_URL=https://xxxx.ngrok.io`.
3. В админке заново сохранить настройки Telegram (токен + «Бот включён») — вебхук перерегистрируется на ngrok-URL.
4. После тестов при деплое на сервер снова сохранить настройки с реальным `APP_URL` — вебхук обновится на продакшен-домен.

---

## 10. Команды бота (кратко)

| Команда   | Описание |
|----------|----------|
| `/start` | Без кода — подсказка, как привязать аккаунт. С кодом — привязка аккаунта. |
| `/balance` | Показать баланс по всем видимым румам (с учётом настроек отображения). |

---

## 11. Отключение или смена бота

- В админке снимите галочку **«Бот включён»** и сохраните — пользователи не смогут привязываться и использовать бота.
- Чтобы сменить бота: вставьте новый токен, сохраните. Вебхук перезапишется на того же URL, но уже для нового бота.
