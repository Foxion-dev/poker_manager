# Документация для пользователей

Краткое руководство по использованию Poker Manager: веб-приложение и Telegram-бот.

## Содержание

1. [Руководство пользователя](guide.md) — пошаговые инструкции: турниры, статистика, локации, паки, настройки, Telegram.
2. [Веб-приложение](app.md) — дашборд, турниры, паки, локации, настройки.
3. [Telegram-бот](telegram.md) — привязка аккаунта и команды бота.

## Регистрация и вход

- Зарегистрируйтесь по адресу приложения (кнопка «Регистрация») или войдите, если уже есть аккаунт.
- После входа доступны: дашборд со статистикой, список турниров и паков, локации (если включены), настройки.
