# Telegram-бот Poker Manager

Бот позволяет получать баланс по румам, статистику за период и добавлять турниры прямо из Telegram.

## Привязка аккаунта

1. В веб-приложении откройте **Настройки** → вкладка **Telegram**.
2. Нажмите **«Получить код»** — появится код и время его действия (обычно несколько минут).
3. В Telegram найдите бота (username указывает администратор) и отправьте:  
   `/start ВАШ_КОД`  
   например: `/start ABC123`.
4. Бот ответит, что аккаунт привязан. После этого доступны все команды.

Если аккаунт уже привязан, при отправке `/start` без кода бот покажет, к какому аккаунту привязан чат.

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Без кода — подсказка, как привязать аккаунт. С кодом — привязка аккаунта. |
| `/balance` | Баланс по всем видимым румам (румы, скрытые в настройках приложения, не показываются). |
| `/get_stats` | Статистика за период. Бот предложит выбрать период кнопками: неделя, месяц, год или свой период (ввод дат). |
| `/add` | Добавить турнир. Пошагово: выбор рума (кнопками), валюты (кнопками), байин, кэшаут (можно пропустить), кэшаут баунти (можно пропустить). |

## Примеры

- **Баланс:** отправьте `/balance` — придёт список румов и балансов в их валютах.
- **Статистика за месяц:** `/get_stats` → нажать кнопку «Месяц» — придёт сводка (турниры/паки, прибыль, ITM, ROI и т.д.).
- **Добавить турнир:** `/add` → выбрать рум → валюту → ввести байин (например `10.5`) → при запросе кэшаута ввести сумму или «пусто»/«-» → то же для кэшаута баунти. Турнир будет создан с сегодняшней датой.

## Отвязка аккаунта

В веб-приложении: **Настройки** → **Telegram** → **Отвязать аккаунт**. После этого бот перестанет иметь доступ к вашим данным; привязку можно повторить, получив новый код.
