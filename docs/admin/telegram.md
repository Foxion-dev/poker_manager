# Настройка Telegram-бота (админ/разработчик)

Полная инструкция по настройке бота на сервере: **[TELEGRAM_BOT_SETUP.md](../TELEGRAM_BOT_SETUP.md)**.

## Кратко

1. Создать бота в [@BotFather](https://t.me/BotFather) (`/newbot`), сохранить токен.
2. В приложении войти под **администратором** → **Админка** → **Настройки** → вкладка **Telegram**.
3. Вставить токен, включить «Бот включён», нажать **Сохранить**. Приложение само зарегистрирует вебхук по адресу `https://APP_URL/api/telegram/webhook`.
4. Требования: сайт по **HTTPS**, в `.env` задан корректный **APP_URL**.

## Проверка вебхука

На сервере:

```bash
php artisan telegram:webhook-info
```

Должен отображаться URL вебхука. Если нет — повторно сохранить настройки Telegram в админке.

## Если бот не отвечает

- Проверить `APP_URL` (HTTPS), выполнить `php artisan config:clear`, снова сохранить настройки бота.
- Просмотреть логи: `tail -f storage/logs/laravel.log` при отправке сообщения боту.
- Убедиться, что миграции выполнены (таблицы `telegram_bot_settings`, `user_settings` и т.д.).

Подробности, Nginx, локальная разработка через ngrok — в [TELEGRAM_BOT_SETUP.md](../TELEGRAM_BOT_SETUP.md).
